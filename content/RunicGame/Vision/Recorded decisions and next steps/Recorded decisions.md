| Topic | Decision |
| :---- | :---- |
| Class | A weapon loadout plus a [[Weapon Class System#Disciplines\|Discipline]] makes a [[Weapon Class System#Named classes\|named class]] with a single role (Damage, Tank or Support); there is no separate role choice |
| Loadouts | Ten fixed [[Weapon Class System#Loadouts\|loadouts]]: Sword \+ Shield, Wand \+ Shield, Wand \+ Focus, Spear, Quarterstaff, Staff, Bow, Instrument, Greatsword and Dual Axes; no versatile weapons; Mace, Dagger, War Axe, the one-handed Axe and hand instruments removed |
| Vertentes | Removed; the class is chosen at the [[Real exploration#Altars, death, respawn and teleports\|Altar]] |
| Disciplines | Five at launch: War, Defense, Vitality, Arcane and Occultism |
| Named classes | 50, with English names; 18 Damage, 15 Tank and 17 Support |
| Class change | Only through the full reset at any Altar, which redistributes the skill points and level choices |
| Weapon swap | None in combat; no weapon-type change outside the Altar reset |
| Skills and points | Weapon skills are the basic kit, unlocked by level at no cost; skill points go only into Discipline skills; one merged tree per class; the same points for everyone at max level; no limit on active skills |
| Ranged | No ranged slot; the Bow is a loadout, and melee loadouts have a few cheap long-range skills |
| Weapon Mastery and Infusion | Removed |
| Context kit | Mount and aerial trees per class, with their own points; mounted, with a glider or with a wing only context skills apply; details being defined |
| Combat rhythm | Slower, inspired by Crimson Desert |
| Combat state | Starts on the first hostile action and ends 30 s after the last one |
| PvE and PvP values | Every value has a base; a skill, item or effect can declare its own PvE and/or PvP values |
| Tank without a shield | Possible; [[Defense Evasion Guard and armor#Guard\|Guard]] without a shield is limited and trades versatility for damage (timed on the Quarterstaff, during the side dash on the Greatsword, during the sprint skill on the Spear, magic Guard for mages) |
| [[Combat#Resolve hard and light CC\|Resolve]] | A full hard CC, then Resolve T1 (about 2 s, the next CC drops a level), then Resolve T2 (about 2 s, immune to every CC); slows capped at about 10 s, then about 5 s of slow immunity; the numbers are examples |
| Conditions | Build-up per source, one acting instance per condition, peaks with an extra effect; Burn, Chill, Shock, Poison, Bleed, Curse, Madness and Acid; detailed rules can change |
| [[Combat#Conditions, build-up and Tolerance\|Tolerance]] | Per condition: after about 10 s of the condition in a row, or at once on a peak, about 5 s of immunity to that condition's build-up; the numbers are examples |
| Environment and CC | Hazards go through Resolve and Tolerance unless their own rule says otherwise (ex.: slips) |
| Role efficiency | Values documented as the starting point, tuned in playtests |
| Balance numbers | Coefficients, ceilings and any specific value are set in development and playtests |
| Damage types | Physical and magical domains with separate armor pools; physical subtypes Slash, Pierce and Blunt against armor weight; magic subtypes Elemental, Arcane and Occult as rules, never item stats |
| Armor | Five pieces; the iframe blends per piece; Guard is the sum of the pieces; total armor reduces damage on a curve that never reaches 100% |
| Damage and effects | The damage type only affects defenses; effects, CC and conditions are declared components |
| Unique effects | Change tags or the element, add an effect or a skill; come from PvE and also from PvP; can be extracted (destroying the item) into a gem |
| Extraction and gems | Extraction is the same process as dismantling; the effect becomes a gem holding an Infusion Rune (flavor), with one socket per weapon; a gem can be socketed, sold or crushed |
| Grades | As documented; the system must make adding or removing grades easy |
| Races | Five: Humans and Dragonkin (Faction 1), Elves and Orcs (Faction 2), Undead in both; one shared skeleton and hitbox; traits are convenience only and will be redefined |
| Pirates | Do PvE with both factions |
| [[Real exploration#Exploration XP\|Exploration XP]] | Spent in the exploration shop on adventurer abilities, resources and maximum [[Stamina and climbing#Stamina\|stamina]]; never combat skills or cosmetics |
| Professions | 23, based on ArcheAge's list; Cartography includes nautical charts and exploration; Larceny includes coin purses; Commerce, Printing and Artistry are professions; masteries per character, 3 active for now |
| Labor | Shared by the Lineage; the same maximum for everyone; only subscribers regenerate offline; a [[Labor#Labor reserve\|labor reserve]] for subscribers that never expires; every [[Labor\|labor]] cost belongs to a profession |
| World maps | One continuous map with the surface, floating islands and the Underground; the Sky Island is a separate map, reached by the island staircase of the neutral continent; no sky layer and no geysers |
| Underground | In the same map, below the surface |
| Floating islands | Inside the surface map, fixed and indestructible; never split between simulation servers |
| Flight | Only on the neutral continent and the Sky Island, unlimited inside the zones, with an altitude ceiling; aerial PvP on the neutral continent |
| Ocean | Only gliding, with the wind current; gliding against it is impossible; sailing is still necessary |
| Currents | A cyclic, mappable base routine; admin events change the routine for a while |
| Gliders, wings and mounts | The glider only glides; the wing is equipment that glides and flies in the flight zones; mounts have gliding and flying as separate capabilities; other vehicles are summoned by scroll |
| Stamina and climbing | Stamina for sprinting, climbing, fast swimming and other non-combat effort; character climbing with stamina; some surfaces never climbable |
| Trade packs | World objects outside the inventory; drop on death or when the vehicle is destroyed or dismissed; no flying or gliding; specialized vehicles or mounts (one pack per mount); ArcheAge pack types; 80% to the deliverer and 20% to the crafter |
| Map discovery | Account-wide (Lineage); three detail levels; charts per node and per layer, consumed when used; your own position always visible; [[Maps and cartography#Surveying\|surveying]] is PvP |
| Altars | Respawn at the nearest Altar the character has discovered, in the same map; the Lineage sees found Altars on the map, but respawn and teleports need the character's own visit; every city has one |
| Teleports | Only when idle; cost by distance, much higher between continents, no cargo fee; from the field also a consumable and a long cooldown; Altar to Altar only the cost; world portals with a toll, without packs or mounts |
| Death penalty | Light: equipment loses durability; maps, equipment and quest items are not lost; [[Trade packs and routes\|trade packs]] drop on the spot |
| Economy | One world auction with NPC listings at the price cap; one global chest; mail priced per unit; the auction tax kept entirely by the NPC; regional price movement in trade-pack demand |
| Nodes and guilds | A region is a city node with its child nodes; a guild holds at most 3 nodes or one region; a fixed weekly payout by tier and [[Regional economy#Prosperity and node missions\|prosperity]]; weekly [[Regional economy#Prosperity and node missions\|node missions]]; region projects built with packs |
| Castles | Only on the neutral continent, one per region in a designated zone, fixed once placed; on the faction continents the ruling guild uses the city and an exclusive guild building |
| Black market | Four passive goblins buy crafted equipment at the average auction price; bought items go into mob drops; mobs never drop gold |
| Living world | Routines mapped to world time, without simulating empty areas; deterministic drift; player exceptions stored in a service |
| Camera | Close to the character, with no far zoom |
| Business model | A [[Business model launch visuals and audio#Subscription\|subscription]] and no cash shop at all; free-to-play or buy-to-play is open |
| Inventory | No weight, only slots; expansions with in-game money; a special tab for character-bound items; character-bound, account-bound and unbound items |
| [[Inventory equipment and the Market Isle#Market Isle (working name)\|Market Isle]] | An instanced, Mirage Isle-style shop that sells designs, not finished items; designs and what they build are bound |
| Main story | Mandatory, long and non-intrusive; chapters per race, then per faction, mirrored; one thread across every expansion |
| Quests | Activities, never kill or collect chores; no markers over NPCs; an automatic Codex; a timeline Chronicle; asking NPCs through knowledge tags; secrets; quest points |
| Repeated effects between role and Discipline | Don't stack; the strongest wins. Provisional: confirm with the skill pools |
| Starting world size | About 600 km² per map (the surface and the Sky Island), counting land, islands and sea; the world grows with the game live |
| Pillar 8 | Play without obligation: no dailies, login streaks or rewards that punish time away |
| PvE and PvP coexistence | A pillar of the game: one world and one economy; PvP is the default and PvE mode is always available; full combat isolation between the modes in the open world, except in the PvE instance |
| Content and targets | All content is PvE, PvP or PvPvE; target discovery is decided by the attacker, without marking ordinary mobs |
| Vocabulary | Participation mode, [[Factions PvP and crime#Jurisdiction\|Jurisdiction]] and Balance Profile are distinct terms; none is ever called just "context" |
| World bosses and the boss region | PvPvE: only PvP mode takes part; world bosses target only PvP players |
| Trade packs and ships | Need PvP mode, even on the safe routes of the starting areas; a ship with a trade pack becomes a PvP ship, with PvE characters aboard only as passengers |
| [[Factions PvP and crime#Outlaw and Infamy\|Outlaw]] and [[Factions PvP and crime#Outlaw and Infamy\|Infamy]] | A toggle skill only in PvP mode; a cooldown of about 30 min restarted by each hit on your own faction; Infamy only for reported kills; enough Infamy makes a pirate; support only from another Outlaw |
| [[Runes\|Runes]] | Nothing is ever called just "Rune": every use carries a qualifier (see Runes) |
| Names | Every specific name in the game is in English |
