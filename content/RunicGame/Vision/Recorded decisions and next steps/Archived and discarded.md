| Idea | Status |
| :---- | :---- |
| Mobile island with a castle | Archived; the architecture should be able to support it |
| Destructible islands | Discarded |
| Exploration points unlocking combat skills or cosmetics | Discarded |
| An aerial counterpart for every skill | Discarded |
| Central shared memory between simulations | Discarded (technical decision) |
| Weapon Mastery and Infusion | Discarded |
| A separate role choice | Discarded; the role comes from the [[Weapon Class System#Named classes\|named class]] |
| Vertentes and free weapon pairs | Discarded on 25 October; replaced by ten fixed [[Weapon Class System#Loadouts\|loadouts]] |
| Versatile weapons; Mace, Dagger, War Axe, the one-handed Axe and hand instruments | Discarded on 25 October |
| One skill tree per weapon and per [[Weapon Class System#Disciplines\|Discipline]] | Discarded; weapon skills are the basic kit and points go into the Discipline |
| Canção, Elementalismo and Sombra as Disciplines | Discarded; merged into the five Disciplines |
| Tank, Healer and DPS | Replaced by Damage, Tank and Support |
| The sea, highland, rock and deep peoples | Discarded; replaced by the five races |
| A sky layer 8 km up, geysers, spatial layers for the Sky and the Underground | Discarded |
| Regional auction houses and local storage | Discarded; one world auction and one global chest |
| A castle in every region | Discarded; castles exist only on the neutral continent |
| [[Real exploration#Altars, death, respawn and teleports\|Altars]] that don't teleport; a cargo fee on teleports | Discarded |
| Map discovery per character; three map types per region | Discarded; map discovery per Lineage and charts per node and layer |
| A short main story | Discarded; the main story is long and non-intrusive |
| Gradual free-to-play as a decision | Reopened as part of the business model |
