**ID:** QUEST-01 · **Status:** In game vision · **Game vision:** [[Quests and story|Quests and story]]

Quests branch like trees: dialogue choices send a quest down different paths, which can branch again, so each leveling run can be different (inspired by Star Wars: The Old Republic). The quest API must support these branches.

* **Voice:** no voice acting at first, only text or fake voice sounds that follow the text. Voice acting comes later, if the game succeeds or gets funding.  
* **Group content while leveling:** group quests and story dungeons along the leveling path.  
* **No level scaling:** zones keep their level, with no scaling of the player to the zone like Guild Wars 2's.  
* **No companions:** no NPC companions that fight or quest with the player.

*(proposal: a quest is a data graph of steps, conditions and outcomes, run by the quest service; choices are stored per character, so an alt can take another branch.)*
