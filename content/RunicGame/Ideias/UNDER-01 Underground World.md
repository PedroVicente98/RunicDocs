**ID:** UNDER-01 · **Status:** In game vision · **Game vision:** [[Open world|Open world]] (Underground); [[Real exploration#Night and lighting|Real exploration › Night and lighting]]

The world has a underground layer, so there is a whole world, underdark style, with underground caves, rivers and oceans. Players access it by caves and rivers from the surface that run downward.Unique Resources and unique npcs and world lore. It has permanent darkness, using the same light system as the night: darkness hides shortcuts, ores and treasure, and creatures react to light. need to be fun not only a deterrent. It is in the same map as the surface, below it, built from sparse 3D cells (no layer system).

*Updated 2026-10-16: darkness decided (was: might have a darkness mechanic or something that make it special, like flight in sky islands); same map below the surface (was: layer system from spatial partitioning).*
