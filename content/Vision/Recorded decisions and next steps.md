### Recorded decisions

| Topic | Decision |
| :---- | :---- |
| Class | A weapon loadout plus a Discipline makes a named class with a single role (Damage, Tank or Support); there is no separate role choice |
| Loadouts | Ten fixed loadouts: Sword \+ Shield, Wand \+ Shield, Wand \+ Focus, Spear, Quarterstaff, Staff, Bow, Instrument, Greatsword and Dual Axes; no versatile weapons; Mace, Dagger, War Axe, the one-handed Axe and hand instruments removed |
| Vertentes | Removed; the class is chosen at the Altar |
| Disciplines | Five at launch: War, Defense, Vitality, Arcane and Occultism |
| Named classes | 50, with English names; 18 Damage, 15 Tank and 17 Support |
| Class change | Only through the full reset at any Altar, which redistributes the skill points and level choices |
| Weapon swap | None in combat; no weapon-type change outside the Altar reset |
| Skills and points | Weapon skills are the basic kit, unlocked by level at no cost; skill points go only into Discipline skills; one merged tree per class; the same points for everyone at max level; at most 28 combat skills (weapon plus Discipline), with emotes, the context kit and other auxiliary skills in their own categories |
| Ranged | No ranged slot; the Bow is a loadout, and melee loadouts have a few cheap long-range skills |
| Weapon Mastery and Infusion | Removed |
| Context kit | Mount and aerial trees per class, with their own points; mounted, with a glider or with a wing only context skills apply; details being defined |
| Combat rhythm | Slower, inspired by Crimson Desert |
| Combat state | Starts on the first hostile action and ends 30 s after the last one |
| PvE and PvP values | Every value has a base; a skill, item or effect can declare its own PvE and/or PvP values |
| Tank without a shield | Possible; Guard without a shield is limited and trades versatility for damage (timed on the Quarterstaff, during the side dash on the Greatsword, during the sprint skill on the Spear, magic Guard for mages) |
| Resolve | A full hard CC, then Resolve T1 (about 2 s, the next CC drops a level), then Resolve T2 (about 2 s, immune to every CC); slows capped at about 10 s, then about 5 s of slow immunity; the numbers are examples |
| Conditions | Build-up per source, one acting instance per condition, peaks with an extra effect; Burn, Chill, Shock, Poison, Bleed, Curse, Madness and Acid; detailed rules can change |
| Tolerance | Per condition: after about 10 s of the condition in a row, or at once on a peak, about 5 s of immunity to that condition's build-up; the numbers are examples |
| Environment and CC | Hazards go through Resolve and Tolerance unless their own rule says otherwise (e.g. slips) |
| Role efficiency | Values documented as the starting point, tuned in playtests |
| Balance numbers | Coefficients, ceilings and any specific value are set in development and playtests |
| Damage types | Physical and magical domains with separate armor pools; physical subtypes Slash, Pierce and Blunt against armor weight; magic subtypes Elemental, Arcane and Occult as rules, never item stats |
| Armor | Five pieces; the iframe blends per piece; Guard is the sum of the pieces; total armor reduces damage on a curve that never reaches 100% |
| Damage and effects | The damage type only affects defenses; effects, CC and conditions are declared components |
| Unique effects | Change tags or the element, add an effect or a skill; come from PvE and also from PvP; can be extracted (destroying the item) into a gem |
| Extraction and gems | Extraction is the same process as dismantling; the effect becomes a gem holding an Infusion Rune (flavor), with one socket per weapon; a gem can be socketed, sold or crushed |
| Grades | As documented; the system must make adding or removing grades easy |
| Races | Five: Humans and Dragonkin (Faction 1), Elves and Orcs (Faction 2), Undead in both; one shared skeleton and hitbox; traits are convenience only and will be redefined |
| Pirates | Do PvE with both factions |
| Exploration XP | Spent in the exploration shop on adventurer abilities, resources and maximum stamina; never combat skills or cosmetics |
| Professions | 23, based on ArcheAge's list; Cartography includes nautical charts and exploration; Larceny includes coin purses; Commerce, Printing and Artistry are professions; masteries per character, 3 active for now |
| Labor | Shared by the Lineage; the same maximum for everyone; only subscribers regenerate offline; a labor reserve for subscribers that never expires; every labor cost belongs to a profession |
| World maps | One continuous map with the surface, floating islands and the Underground; the Sky Island is a separate map (how it is reached is being defined); no sky layer and no geysers |
| Underground | In the same map, below the surface |
| Floating islands | Inside the surface map, all in the flight-zone region of the neutral continent; fixed and indestructible; never split between simulation servers |
| Flight | Only in flight zones: special regions of the neutral continent, for now one (the region of the floating islands), and the Sky Island; unlimited inside the zones, with an altitude ceiling; aerial PvP in the neutral continent's flight zone |
| Ocean | Only gliding, with the wind current; gliding against it is impossible; sailing is still necessary |
| Currents | A cyclic, mappable base routine; admin events change the routine for a while |
| Gliders, wings and mounts | The glider only glides; the wing is equipment that glides and flies in the flight zones; mounts have gliding and flying as separate capabilities; other vehicles are summoned by scroll |
| Stamina and climbing | Stamina for sprinting, climbing, fast swimming and other non-combat effort; character climbing with stamina; some surfaces never climbable |
| Trade packs | World objects outside the inventory; drop on death or when the vehicle is destroyed or dismissed; no flying or gliding; specialized vehicles or mounts (one pack per mount); ArcheAge pack types; 80% to the deliverer and 20% to the crafter |
| Map discovery | Account-wide (Lineage); three detail levels; charts per node and per layer, consumed when used; your own position always visible; surveying is PvP |
| Altars | Respawn at the nearest Altar the character has discovered, in the same map; the Lineage sees found Altars on the map, but respawn and teleports need the character's own visit; every city has one |
| Teleports | Only when idle; cost by distance, much higher between continents, no cargo fee; from the field also a consumable and a long cooldown; Altar to Altar only the cost; world portals with a toll, without packs or mounts |
| Death penalty | Light: equipment loses durability; maps, equipment and quest items are not lost; trade packs drop on the spot |
| Economy | One world auction with NPC listings at the price cap; one global chest; mail priced per unit; the auction tax kept entirely by the NPC; regional price movement in trade-pack demand |
| Nodes and guilds | A region is a city node with its child nodes; a guild holds at most 3 nodes or one region; a fixed weekly payout by tier and prosperity; weekly node missions; region projects built with packs |
| Castles | Only on the neutral continent, one per region in a designated zone, fixed once placed; on the faction continents the ruling guild uses the city and an exclusive guild building |
| Black market | Four passive goblins buy crafted equipment at the average auction price; bought items go into mob drops; mobs never drop gold |
| Living world | Routines mapped to world time, without simulating empty areas; deterministic drift; player exceptions stored in a service |
| Camera | Close to the character, with no far zoom |
| Business model | A subscription and no cash shop at all; free-to-play or buy-to-play is open |
| Inventory | No weight, only slots; expansions with in-game money; a special tab for character-bound items; character-bound, account-bound and unbound items |
| Market Isle | An instanced, Mirage Isle-style shop that sells designs, not finished items; designs and what they build are bound |
| Main story | Mandatory, long and non-intrusive; chapters per race, then per faction, mirrored; one thread across every expansion |
| Quests | Activities, never kill or collect chores; no markers over NPCs; an automatic Codex; a timeline Chronicle; asking NPCs through knowledge tags; secrets; quest points |
| Repeated effects between role and Discipline | Don't stack; the strongest wins. Provisional: confirm with the skill pools |
| Starting world size | The surface map is 51.2 × 51.2 km (about 2,621 km²), with about 600 km² of land as a baseline that follows the content and sea around every continent; the Sky Island map is the same size; the world grows with the game live |
| Pillar 8 | Play without obligation: no dailies, login streaks or rewards that punish time away |
| PvE and PvP coexistence | A pillar of the game: one world and one economy; PvP is the default and PvE mode is always available; full combat isolation between the modes in the open world, except in the PvE instance |
| Content and targets | All content is PvE, PvP or PvPvE; target discovery is decided by the attacker, without marking ordinary mobs |
| Vocabulary | Participation mode, Jurisdiction and Balance Profile are distinct terms; none is ever called just "context" |
| World bosses and the boss region | PvPvE: only PvP mode takes part; world bosses target only PvP players |
| Trade packs and ships | Need PvP mode, even on the safe routes of the starting areas; a ship with a trade pack becomes a PvP ship, with PvE characters aboard only as passengers |
| Outlaw and Infamy | A toggle skill only in PvP mode; a cooldown of about 30 min restarted by each hit on your own faction; Infamy only for reported kills; enough Infamy makes a pirate; support only from another Outlaw |
| Runes | Nothing is ever called just "Rune": every use carries a qualifier (see [[Runes]]) |
| Names | Every specific name in the game is in English |

### Still proposed

* A soft flight ceiling.  
* Group and raid sizes.  
* The Balance Profile decided by the target of each hit.  
* Cloth with the longest iframe and plate the shortest.  
* The armor curve A ÷ (A \+ K).  
* Bosses with a Break bar instead of hard CC.  
* The peaks of Poison, Curse and Madness, and the 60% cap per skill on a bar.  
* The dodge shapes of Arcane and Occultism, carried over from the removed Disciplines.  
* Defense's exclusive (absorb barriers, restoring Guard and reflect).  
* The cost of inventory expansions growing up to a maximum.  
* Language as a requirement to change faction.  
* Each current event defining from when it can be predicted.  
* Photo mode only out of combat.  
* Outlaw staying on after death.  
* A chapter needing some of its region's arcs; chapter replays as Altar memories.  
* Four quest guidance levels.  
* The pack overriding the back slot without unequipping the glider.  
* Soul Runes as the name of the runes of living beings.

### Being defined (Open)

* The mount and aerial trees per class: balancing how easy it is to create new skills with the quality of aerial combat.  
* The base business model (free-to-play or buy-to-play) and, with it, the launch plan.  
* Defense's dodge shape and Vitality's exclusive; the Dual Axes' signature mechanic.  
* Where the Undead start before choosing a faction, which race starts in which area, and the new race traits.  
* The cooldown and requirements of switching between the PvE and PvP modes.  
* The Infamy limit to become a pirate and the rate at which Infamy decays.  
* Whether pirates can return to a continental faction.  
* Whether picking up a dropped trade pack from your own faction is a crime.  
* Whether a PvE mode player needs to switch to PvP to commit the crime required to change faction.  
* Whether profession proficiency is account-wide or per character.  
* Whether climbing mounts use stamina.  
* The name of the runes of living beings, the special resource from coin purses, quest points and the Market Isle.  
* How story NPCs who die or turn traitor work in a shared world.  
* How players reach the Sky Island, now that the island staircase is gone.

### Risks

* **Scope:** a giant, dense world, the Sky Island, naval and aerial combat and the boss region are a lot of content. Each system should start as a small vertical slice.  
* **Named classes:** 50 classes, each with mount and aerial trees, multiply the content and balance work; the merged trees and shared pools exist to keep it manageable, and launch can start with fewer.  
* **Barrier to entry:** hard mobs and dark nights can push new players away; the first region must teach blocking, dodging and light before punishing.  
* **Launch population:** whatever the base model, opening the servers needs monitoring to decide the pace.  
* **Writing cost:** a long story, a Codex and NPC knowledge profiles need cheap writing tools (taxonomy, role templates, coverage reports).

### Next steps

1. An arena prototype with three named classes, one per role: Guardian (Sword \+ Shield \+ Defense, Tank), Lancer (Spear \+ War, Damage) and Priest (Wand \+ Focus \+ Vitality, Support), with the merged skill trees, Evasion, Guard per weapon, armor per piece, Resolve and condition build-up.  
2. Implement the Skill API: components, timing profiles per weapon, interaction rules, condition build-up and PvE and PvP values, with the two-moment resolver on the server.  
3. Validate role efficiency, component coefficients and the build-up speeds with training dummies before building more loadouts.  
4. A vertical slice of exploration: one region with night, light, regional mobs, Altars, one node with charts and the map per Lineage.  
5. Design the mount and aerial trees and aerial combat before the flight zones.  
6. Write the first quests in the RunicWorld vault, with the Codex and the Chronicle (see [[RunicGame — Quest Design]]).
