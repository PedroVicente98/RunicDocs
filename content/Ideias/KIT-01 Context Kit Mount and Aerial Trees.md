**ID:** KIT-01 · **Status:** Being designed · **Game vision:** [[Weapon Class System#Context kit mount, glider and wing|Weapon Class System › Context kit: mount, glider and wing]]

Each named class has a mount tree and an aerial tree, with their own points earned by level, separate from the combat trees.

Mounted, on a glider or with a wing, the character uses only the context skills. The mount, glider or wing can modify the kit (ex.: Run becomes a Dash with the same buff and an animation before it; a mount brings its own elemental skill). The mount kit is the same on the ground and flying.

**Being designed:** balance how easy it is to create new skills with the quality of aerial combat.
