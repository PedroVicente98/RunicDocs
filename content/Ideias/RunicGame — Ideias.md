**How this file works**

* Every idea has an **ID** that is never reused, and a **status**.

* **Status:**

  * **Open**: only in this file.

  * **Partial**: part of it is in the game vision; the rest is listed under *Not in the game vision yet*.

  * **Being designed**: in the game vision, marked *being defined* or *Open*.

  * **In game vision**: decided and in the game vision. Parts marked *(proposal)* are still proposals there.

  * **Archived** or **Discarded**: in the game vision’s archived table.

* **Conflict** subsection: this file and the game vision disagree, and it isn’t decided yet. It appears under every title the conflict touches. When its status says it was decided in this file, only the game vision is left to update.

* **Updated** line: the text was changed on that date to match the game vision; it says what the old text was.

* **Game vision** in the ID line: the section of *RunicGame — Visão Completa do MMORPG* (titled *RunicGame — Complete MMORPG Vision* inside the document) where the idea lives.
