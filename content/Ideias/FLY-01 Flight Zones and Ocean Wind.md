**ID:** FLY-01 · **Status:** In game vision · **Game vision:** [[Open world]] (flight, ocean, currents)

Flight only exists in flight zones: special regions of the neutral continent, not the whole continent, and the Sky Island. For now the neutral continent has one, the region of the floating islands (where there are floating islands there is flight); more may come later. It is the precursor of the full flight experience of the Sky Island. Inside these zones flight is infinite, with an altitude ceiling above which you can only glide *(proposal: soft ceiling)*. There is aerial PvP in the neutral continent's flight zone.

In the ocean you can only glide, using the wind current, which has a direction (any angle) and a speed. Speed 0 has no effect; a negative speed suddenly reverses the direction without changing the angle. Gliding against the current is impossible, and the character is pushed back. Sailing is still needed.

Sea and wind currents follow a cyclic base routine that can be mapped. Admins create events in a panel that change them for a while; then the base returns. Cartographers map the routine and, at max level, predict events *(proposal: each event defines from when it can be predicted)*.

*Updated 2026-11-03: flight zones are special regions of the neutral continent, for now the floating-island region (was: flight only exists in the neutral continent and the Sky Island; inside these zones flight is infinite; there is aerial PvP in the neutral continent).*
